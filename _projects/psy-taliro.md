description: >-
  $\Psi$-TaLiRo is a toolbox for search-based test generation (SBTG), which is a process for
  evaluating a system against a given behavioral requirement that it must satisfy. The objective
  is to identify a set of inputs which cause the system to demonstrate behavior which violates
  the requirement. This process is generally used to verify that a system does not contain any
  *unsafe* behavior.
